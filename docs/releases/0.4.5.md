# S3 Studio 0.4.5

## English

- Set a global S3 Endpoint and Region under Settings → Global S3 defaults. Buckets inherit each value when its matching account field is blank. Saved account values take precedence.
- Turned off automatic capitalization in web and WebView text fields to preserve case-sensitive input.

Supports Windows x64, macOS Universal, Ubuntu 22.04+ amd64, Linux AppImage, and Omarchy x86_64.

### If macOS cannot open the app

Move S3 Studio into Applications, verify the official release source and SHA-256, then run:

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 在「设置 → S3 全局默认值」中设置 Endpoint 和 Region。账户字段留空时，其存储桶按字段继承全局配置。已填写的账户配置优先。
- 关闭网页和 WebView 文本输入框的自动首字母大写，保留输入的大小写。

支持 Windows x64、macOS Universal、Ubuntu 22.04+ amd64、Linux AppImage 和 Omarchy x86_64。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
