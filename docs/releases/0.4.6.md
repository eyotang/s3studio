# S3 Studio 0.4.6

## English

- Open Global S3 Defaults from the top of Settings.
- When adding or editing an account, Endpoint and Region appear immediately after the account name, before the credentials.

Download the installer for your platform and verify its checksum against `SHA256SUMS.txt`. Installers are available for Windows x64, macOS Universal, Ubuntu 22.04+ amd64, Linux AppImage, and Omarchy x86_64.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 将「S3 全局默认值」入口移到设置顶部。
- 新增或编辑账户时，Endpoint 和 Region 紧跟在账户名称之后、凭据之前。

```bash

```
