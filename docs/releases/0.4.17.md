# S3 Studio 0.4.17

## English

- Application settings open from the **S3 Studio** menu on macOS or with `Cmd+,`. Use `Ctrl+,` on Windows and Linux. The **Transfers** panel shows task status and concurrency.
- The bucket header shows its name and the upload action. Right-click a bucket in the sidebar for its connection settings.
- Add a workspace with the plus button beside **Workspace**. Its card menu provides **Update** and **Delete**, with confirmation before removing any local configuration.

Download your platform’s package from the official GitHub Release and check its hash against `SHA256SUMS.txt`. The Universal DMG supports Apple Silicon and Intel on macOS 14 or later. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. A deb package is available for Ubuntu 22.04+ amd64, an AppImage for Linux x86_64, and a pacman package for Omarchy and Arch x86_64. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

The Windows installers and AppImage support signed in-app updates. Pause or finish active transfers before installing an update. macOS packages currently use a self-signed certificate without an Apple Team ID. Keychain may request authorization again after each upgrade, even if you previously selected Always Allow; the fixed certificate does not prevent CDHash-based partition checks.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- macOS 从「S3 Studio → 设置…」或用 `⌘+,` 打开应用设置。Windows 和 Linux 使用 `Ctrl+,`。「传输活动」面板集中展示任务状态和并发数。
- 桶标题区域保留桶名和上传入口。需要配置桶的连接时，在侧栏右键点击对应桶。
- 在「工作空间」标题旁点击 `+` 添加工作空间。每张工作空间卡片的菜单提供「更新」和「删除」，移除本机配置前会要求确认。

从官方 GitHub Release 下载对应平台的安装包，并用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。NSIS 和 MSI 安装包需要 Windows 10 1809 或更高版本的 x64 系统。Ubuntu 22.04+ amd64 提供 deb 包，Linux x86_64 提供 AppImage，Omarchy 和 Arch x86_64 使用 pacman 包。Linux 需要已解锁的 Secret Service 密钥库来存取凭据，并需要桌面文件选择 portal。启动 AppImage 前请添加执行权限。

Windows 安装版和 AppImage 支持应用内签名更新。安装更新前请暂停或完成正在进行的传输。macOS 安装包目前使用没有 Apple Team ID 的自签名证书。即使此前选择过「始终允许」，每次升级后钥匙串仍可能再次要求授权；固定证书无法避免基于 CDHash 的分区检查。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
