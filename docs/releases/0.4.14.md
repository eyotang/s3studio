# S3 Studio 0.4.14

## English

- The object search field recognizes full S3 paths automatically. The separate **Go to path** toolbar button has been removed.
- The clear button sits inside the right edge of the search field. Clearing keeps keyboard focus in the field so you can type again immediately.
- For an object key ending in `/`, press `Shift+Enter` in the search field and choose **Exact object only**.

Download your platform’s package from the official GitHub Release and check its hash against `SHA256SUMS.txt`. The Universal DMG supports Apple Silicon and Intel on macOS 14 or later. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. A deb package is available for Ubuntu 22.04+ amd64, an AppImage for Linux x86_64, and a pacman package for Omarchy and Arch x86_64. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

The Windows installers and AppImage support signed in-app updates. Pause or finish active transfers before installing an update.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

### macOS 无法打开应用

sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
