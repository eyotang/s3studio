# S3 Studio 0.4.10

## English

- The object tree saves directory totals and object keys to a local SQLite cache. Reopening a tree reuses the previous scan, including after restart. Expanded folders and search results load in pages.
- The tree shows the last scan time and flags caches that are 24 hours old or need verification. Refresh rescans the selected folder while keeping the previous results available. A completed scan replaces the previous cache.
- Confirmed uploads, copies, folder creation, and deletions in S3 Studio update the corresponding cached totals. Use Refresh to pick up changes from other clients. The first scan and manual refresh still enumerate the selected scope and need local disk space.

Download your platform’s package from the official GitHub Release and check its hash against `SHA256SUMS.txt`. The Universal DMG supports Apple Silicon and Intel on macOS 14 or later. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. A deb package is available for Ubuntu 22.04+ amd64, an AppImage for Linux x86_64, and a pacman package for Omarchy and Arch x86_64. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

The Windows installers and AppImage support signed in-app updates. Pause or finish active transfers before installing an update.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 树状视图将目录汇总和对象键保存在本机 SQLite 缓存中。重新打开树状视图可复用上次扫描结果，应用重启后同样可用。展开目录和搜索结果均按页读取。
- 界面显示上次扫描时间。缓存满 24 小时或需要核对时会提示刷新。点击「刷新」会重新扫描当前目录，扫描期间可以继续查看上次结果。扫描成功后会替换旧缓存。
- 在 S3 Studio 中确认的上传、复制、新建目录和删除会更新对应的缓存汇总。其他客户端的改动可通过「刷新」同步。首次扫描和手动刷新需要完整列举当前范围，并占用本机磁盘空间。

从官方 GitHub Release 下载对应平台的安装包，并用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。NSIS 和 MSI 安装包需要 Windows 10 1809 或更高版本的 x64 系统。Ubuntu 22.04+ amd64 提供 deb 包，Linux x86_64 提供 AppImage，Omarchy 和 Arch x86_64 提供 pacman 包。Linux 需要已解锁的 Secret Service 密钥库来存取凭据，并需要桌面文件选择 portal。启动 AppImage 前请添加执行权限。

Windows 安装版和 AppImage 支持应用内签名更新。安装更新前请暂停或完成正在进行的传输。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
