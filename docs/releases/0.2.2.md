# S3 Studio 0.2.2

跨平台图形化 S3 客户端，支持 Windows、macOS 和 Ubuntu，账户数量不设上限。

## 功能

- 浅蓝色层叠 Logo，统一桌面图标与应用界面。
- AWS S3 和自定义 Endpoint 的 S3 兼容服务。
- 存储桶与对象浏览、上传、下载、复制、删除及预签名分享链接。
- 并发分片上传与 Range 下载，应用级默认 8 路并发，可调整为 1–32 路。
- 暂停、继续、失败重试；应用重启后可手动断点续传。
- AK、SK 和 Session Token 存储在系统密钥库中。

## 下载与安装

| 平台                        | 安装包                                                      |
| --------------------------- | ----------------------------------------------------------- |
| Windows x64                 | `windows_x64-setup.exe` 或 `windows_x64.msi`                |
| macOS Apple Silicon / Intel | `macOS_universal.dmg`，打开后将 S3 Studio 拖入 Applications |
| Ubuntu 22.04+ amd64         | `ubuntu22.04_amd64.deb`                                     |
| Linux x86_64                | `linux_x86_64.AppImage`，添加执行权限后启动                 |

文件均以 `S3-Studio_0.2.2_` 为前缀。`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。

Ubuntu 桌面需要 WebKitGTK 4.1 和已运行、解锁的 Secret Service 密钥库，例如 GNOME Keyring。

本版本未进行 Windows 代码签名、macOS 代码签名或公证，系统可能提示来源无法验证。macOS 如受 Gatekeeper 阻止，可在系统设置的「隐私与安全性」中允许打开；安装前请确认来源与校验值。

## 验证与范围

发布流程分别在 Windows、macOS 和 Ubuntu 上运行前端基础测试、Rust 测试并构建安装包，三平台全部成功后才发布。macOS 安装包同时包含 arm64 和 x86_64。

传输测试使用本地模拟 S3 服务。实际云服务兼容性及三个平台的交互操作仍需要实际使用验证；当前不含 SSO、ACL/策略编辑、版本管理、目录同步和跨账户复制。
