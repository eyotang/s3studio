# S3 Studio 0.4.3

## English

- Fixed the macOS native titlebar remaining light when a dark app theme was selected.
- Native window appearance now follows the selected theme. Choosing Follow System clears the manual override.
- The settings confirmation now reads “Settings saved successfully”, with matching Chinese text.

Supports Windows x64, macOS Universal, Ubuntu 22.04+ amd64, Linux AppImage, and Omarchy x86_64.

### If macOS cannot open the app

Move S3 Studio into Applications, verify the official release source and SHA-256, then run:

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
