# S3 Studio 0.4.8

## English

- Rebuilt the desktop workspace in Native Shell. Account and bucket settings, object browsing and file actions, transfer controls, all seven interface languages, and automatic and manual update checks are available in the new interface.
- Existing installations retain their connection settings, credentials in the system keychain, transfer history and resumable checkpoints, and saved language and theme preferences.
- Removed the old web frontend, npm dependencies, and Tauri. The NSH executable is packaged directly for each platform, and Windows and AppImage updates use the existing Minisign key. Windows installers omit WebView2 setup.

Download your platform's package from the official GitHub Release and verify it against `SHA256SUMS.txt`. The macOS Universal DMG supports Apple Silicon and Intel on macOS 14 or later. Windows x64 offers NSIS and MSI installers. Ubuntu 22.04+ amd64 offers a deb package, Linux x86_64 has an AppImage, and Omarchy / Arch x86_64 uses a pacman package. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

Windows installers and AppImage support signed in-app updates. Pause or finish active transfers before installing an update.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 从已有版本升级时，连接设置、系统密钥库中的凭据、传输记录与续传断点，以及已保存的语言和主题设置都会保留。
- 移除旧网页前端、npm 依赖和 Tauri。安装包直接封装 NSH 可执行文件，Windows 和 AppImage 更新沿用原有 Minisign 密钥。Windows 安装包移除了 WebView2 安装步骤。

从官方 GitHub Release 下载对应平台的安装包，并用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。Windows x64 提供 NSIS 和 MSI 安装包，Ubuntu 22.04+ amd64 提供 deb 包，Linux x86_64 提供 AppImage，Omarchy / Arch x86_64 使用 pacman 包。Linux 需要已解锁的 Secret Service 密钥库来存取凭据，并需要桌面文件选择 portal。启动 AppImage 前请添加执行权限。

Windows 安装版和 AppImage 支持应用内签名更新。安装更新前请暂停或完成正在进行的传输。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
