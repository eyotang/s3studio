# S3 Studio 0.2.3

## 新增

- 支持直接删除选中的目录，同时递归删除所有子目录和文件。删除前展示所选路径和递归范围；后端遍历完整分页，以每批最多 1000 个对象删除，文件成功删除后再删除目录标记。
- 底栏新增软件更新入口。发布版启动 20 秒后检查新版本，此后每 24 小时检查；自动检查失败保持安静，手动检查展示错误。
- Windows NSIS / MSI 安装版及 Linux AppImage 支持应用内下载更新，校验更新包签名和签名中的版本号后安装。只有确认「下载并安装」后才开始下载，安装前必须暂停或完成传输；暂停断点与账户配置会保留。
- macOS、Ubuntu deb 和直接运行的可执行文件通过更新窗口打开版本下载页。开发模式和网页预览不检查更新。

## 下载与安装

| 平台                        | 安装包                                            |
| --------------------------- | ------------------------------------------------- |
| Windows x64                 | `S3-Studio_0.2.3_windows_x64-setup.exe` 或 `.msi` |
| macOS Apple Silicon / Intel | `S3-Studio_0.2.3_macOS_universal.dmg`             |
| Ubuntu 22.04+ x64           | `S3-Studio_0.2.3_ubuntu22.04_amd64.deb`           |
| Linux x64                   | `S3-Studio_0.2.3_linux_x86_64.AppImage`           |

AppImage 下载后执行 `chmod +x S3-Studio_0.2.3_linux_x86_64.AppImage`，再运行。Ubuntu 需要启用并解锁支持 Secret Service 的系统密钥库。

macOS：打开 DMG，将 **S3 Studio.app** 拖入「应用程序」。当前版本未进行 Apple 开发者签名或公证。若系统阻止打开，确认文件来自本仓库 Release 并核对 `SHA256SUMS.txt` 后，对此应用清除隔离属性：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

然后在「应用程序」中启动。macOS 后续更新仍通过下载页安装；更新包签名与系统代码签名是独立机制。

## 更新文件

本次发布包含五个安装包、Windows NSIS / MSI 与 AppImage 的 `.sig` 签名、`latest.json` 更新清单及 `SHA256SUMS.txt`。所有自动更新文件在发布前验证签名、公钥和版本绑定；三平台构建全部成功后才正式发布。

首次从 0.2.2 升级需下载安装 0.2.3，此前版本没有内置更新入口。

目录删除作用于当前可见对象，不清除版本控制桶的历史版本；服务端设置决定恢复行为。删除期间请避免向同一目录写入新对象，删除对象枚举完成后新上传的对象不会被本次操作删除。
