# S3 Studio 0.3.0

## 本次更新

- 桌面界面迁移到 GPUI 与 GPUI Kit，保留账户、存储桶、文件列表和网格、对象详情、传输活动及原有操作流程。
- 新建账户默认勾选路径兼容模式；编辑已有账户时保留原来的设置。
- 移除存储桶标题末尾的蓝色装饰点。
- 接入原有版本更新机制。应用名称仍为 **S3 Studio**，应用 ID 仍为 `com.s3studio.desktop`，继续使用原有账户配置、系统密钥库和传输断点。

## 版本更新

发布版启动 20 秒后检查新版本，此后每 24 小时检查。自动检查失败保持安静，手动检查展示错误。

Windows NSIS / MSI 安装版和 Linux AppImage 保留应用内更新：用户确认「下载并安装」后才开始下载；安装前必须暂停或完成传输；更新包经过原有签名及版本绑定校验后安装。macOS、Ubuntu deb 和直接运行的可执行文件仍通过发布页下载更新。更新地址、公钥、Windows 安装模式和发布签名流程保持不变。开发模式与预览不检查更新。

## 下载与安装

| 平台                        | 安装包                                            |
| --------------------------- | ------------------------------------------------- |
| Windows x64                 | `S3-Studio_0.3.0_windows_x64-setup.exe` 或 `.msi` |
| macOS Apple Silicon / Intel | `S3-Studio_0.3.0_macOS_universal.dmg`             |
| Ubuntu 22.04+ x64           | `S3-Studio_0.3.0_ubuntu22.04_amd64.deb`           |
| Linux x64                   | `S3-Studio_0.3.0_linux_x86_64.AppImage`           |

AppImage 下载后执行 `chmod +x S3-Studio_0.3.0_linux_x86_64.AppImage`，再运行。Ubuntu 需要启用并解锁支持 Secret Service 的系统密钥库。

macOS：打开 DMG，将 **S3 Studio.app** 拖入「应用程序」。当前版本未进行 Apple 开发者签名或公证。若系统阻止打开，确认文件来自本仓库 Release 并核对 `SHA256SUMS.txt` 后，对此应用清除隔离属性：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

然后在「应用程序」中启动。macOS 后续更新仍通过下载页安装；更新包签名与系统代码签名是独立机制。

发布附件包含五个安装包、Windows NSIS / MSI 与 AppImage 的三份 `.sig` 签名、`latest.json` 和 `SHA256SUMS.txt`。三平台构建和更新签名验证全部成功后才正式发布。
