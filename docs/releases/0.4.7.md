# S3 Studio 0.4.7

## English

- Choose an Endpoint and Region when creating a bucket, or edit the local connection settings for an existing bucket from Bucket Settings. Blank fields inherit the account settings and then the global defaults.
- Pick saved Endpoint and Region values or add new ones from the bucket, account, or global settings forms. Remove saved choices in Global S3 Defaults. Explicit account and bucket settings keep their saved values.

Download the installer for your platform and verify it against `SHA256SUMS.txt`. Installers are available for Windows x64, macOS Universal, Ubuntu 22.04+ amd64, Linux AppImage, and Omarchy x86_64.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 创建存储桶时可选择 Endpoint 和 Region，也可在「存储桶设置」中修改已有桶的本机连接配置。字段留空时依次继承账户配置和全局默认值。
- 在桶、账户和全局设置中可下拉选择已保存的 Endpoint 和 Region，或输入新值后点击「新增」。在「S3 全局默认值」中可删除选项，已写入账户和桶的值仍然有效。

下载对应平台的安装包，并使用 `SHA256SUMS.txt` 核对校验值。支持 Windows x64、macOS Universal、Ubuntu 22.04+ amd64、Linux AppImage 和 Omarchy x86_64。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
