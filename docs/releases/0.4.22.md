# S3 Studio 0.4.22

## English

- The native updater no longer requires Tauri/Minisign signing keys or `.sig` files. It downloads only versioned assets from the official GitHub Release over HTTPS and checks SHA-256 before installation. Checksums detect corruption; release authenticity now relies on HTTPS and the GitHub repository.
- **Migration:** users of versions that require Minisign signatures must manually install this release once. Future updates use the new manifest format.

- macOS releases now use an Apple-issued Developer ID Application certificate with a stable Team ID. Signing verifies both architectures against the Apple certificate chain and expected team.
- Fix macOS Bash compatibility and independently verify signatures before creating the DMG.
- Includes the Endpoint and Region dropdown alignment and original theme colors from 0.4.19.

Download your platform’s package from the official GitHub Release and check its hash against `SHA256SUMS.txt`. The Universal DMG supports Apple Silicon and Intel on macOS 14 or later. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. A deb package is available for Ubuntu 22.04+ amd64, an AppImage for Linux x86_64, and a pacman package for Omarchy and Arch x86_64. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

The Windows installers and AppImage support in-app updates with SHA-256 integrity checks. Pause or finish active transfers before installing an update. Upgrading from the previous self-signed macOS releases may require one more Keychain authorization. Subsequent releases signed by the same Apple team can retain that authorization. This release changes code signing; it does not add Apple notarization.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 原生更新器不再依赖 Tauri/Minisign 签名密钥和 `.sig` 文件。仅通过 HTTPS 下载官方 GitHub Release 对应版本的安装包，并在安装前校验 SHA-256。校验和用于检测文件损坏，发布来源信任依赖 HTTPS 和 GitHub 仓库。
- **升级提示：**仍要求 Minisign 签名的旧版本需要手动安装本版本一次，此后使用新的更新清单格式。

- macOS 正式版改用 Apple 签发的 Developer ID Application 证书和稳定 Team ID，构建时验证两个架构的 Apple 证书链与团队身份。
- 修复 macOS Bash 兼容问题，在生成 DMG 前独立验证签名，防止错误产物被打包。
- 包含 0.4.19 的 Endpoint 和 Region 箭头位置及原有主题配色修复。

从官方 GitHub Release 下载对应平台的安装包，并用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。NSIS 和 MSI 安装包需要 Windows 10 1809 或更高版本的 x64 系统。Ubuntu 22.04+ amd64 提供 deb 包，Linux x86_64 提供 AppImage，Omarchy 和 Arch x86_64 使用 pacman 包。Linux 需要已解锁的 Secret Service 密钥库来存取凭据，并需要桌面文件选择 portal。启动 AppImage 前请添加执行权限。

Windows 安装版和 AppImage 支持带 SHA-256 完整性校验的应用内更新。安装更新前请暂停或完成正在进行的传输。从此前自签名版本升级后，旧钥匙串凭据可能还需要授权一次；后续由同一 Apple 团队签名的版本可沿用该授权。本次更换代码签名，尚未加入 Apple 公证。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
