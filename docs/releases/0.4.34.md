# S3 Studio 0.4.34

## English

- Windows now registers a native window menu bar, matching the macOS menu organization: S3 Studio contains About, Check for Updates, Settings and Quit; Edit provides the standard editing commands. Settings uses Ctrl+, on Windows and Command+, on macOS.
- Removed the brand-title dropdown on Windows and macOS. No extra action-button row is added; macOS keeps its native system menu and Services. Linux retains its in-window dropdown as a fallback.
- Recycle Bin uses a dedicated blue open wastebasket icon, distinct from Delete, and remains first in bucket root listings.
- Windows NSIS and MSI installations support in-app download, SHA-256 verification, installation and relaunch. Install this release manually once if an older version has no accessible update entry point.

Download your platform’s package from the official GitHub Release and check its hash against `SHA256SUMS.txt`. The Universal DMG supports Apple Silicon and Intel on macOS 14 or later. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. A deb package is available for Ubuntu 22.04+ amd64, an AppImage for Linux x86_64, and a pacman package for Omarchy and Arch x86_64. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

Versions before 0.4.22 require a one-time manual installation to migrate from the old update signature format. The Windows installers and AppImage support in-app updates with SHA-256 integrity checks. Pause or finish active transfers before installing an update. Upgrading from the previous self-signed macOS releases may require one more Keychain authorization. Subsequent releases signed by the same Apple team can retain that authorization. This release changes code signing; it does not add Apple notarization.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- Windows 现在使用窗口原生菜单栏，与 macOS 保持一致的菜单组织：「S3 Studio」包含关于、检查更新、设置和退出，「编辑」提供常用编辑命令。设置快捷键在 Windows 为 Ctrl+,，macOS 为 Command+,。
- Windows 和 macOS 移除品牌标题下拉，不增加额外操作按钮行；macOS 保留系统菜单及服务菜单，Linux 保留窗口内下拉作为备用入口。
- 回收站使用独立的蓝色敞口垃圾篓图标，与删除操作区分，并继续位于桶根目录列表第一项。
- Windows NSIS 和 MSI 安装版支持应用内下载、SHA-256 校验、安装和重启；旧版若没有可用更新入口，请先手动安装本版本一次。

从官方 GitHub Release 下载对应平台的安装包，并用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。NSIS 和 MSI 安装包需要 Windows 10 1809 或更高版本的 x64 系统。Ubuntu 22.04+ amd64 提供 deb 包，Linux x86_64 提供 AppImage，Omarchy 和 Arch x86_64 使用 pacman 包。Linux 需要已解锁的 Secret Service 密钥库来存取凭据，并需要桌面文件选择 portal。启动 AppImage 前请添加执行权限。

0.4.22 之前的版本需要手动安装一次，以迁移旧更新签名格式。Windows 安装版和 AppImage 支持带 SHA-256 完整性校验的应用内更新。安装更新前请暂停或完成正在进行的传输。从此前自签名版本升级后，旧钥匙串凭据可能还需要授权一次；后续由同一 Apple 团队签名的版本可沿用该授权。本次更换代码签名，尚未加入 Apple 公证。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
