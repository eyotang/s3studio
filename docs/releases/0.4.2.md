# S3 Studio 0.4.2

- 修复 macOS 手动选择暗色主题后，原生标题栏仍显示亮色的问题。
- 原生窗口外观与应用主题同步；切回「跟随系统」时解除手动外观覆盖，恢复跟随系统。

支持 Windows x64、macOS Universal、Ubuntu 22.04+ amd64、Linux AppImage 和 Omarchy x86_64。

## macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
