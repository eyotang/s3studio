# S3 Studio 0.4.9

## English

- Added an expandable tree view to the bucket object browser. Each folder shows the combined size and object count of its descendants, along with a bar showing its share of the parent folder. The tree sorts by size by default and also supports sorting by name or object count.
- The tree scans the current folder and its subfolders. Open it at the root to scan the full bucket. Searches reveal matching branches and preserve the totals from the complete scan. Scans can be canceled or refreshed. Totals cover current object data and exclude historical versions and unfinished multipart uploads.
- Files in the tree support viewing details, downloading, copying, sharing, and deleting. Selecting a folder allows recursive deletion with confirmation.

Download your platform's package from the official GitHub Release and verify it against `SHA256SUMS.txt`. The macOS Universal DMG supports Apple Silicon and Intel on macOS 14 or later. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. Ubuntu 22.04+ amd64 offers a deb package, Linux x86_64 has an AppImage, and Omarchy / Arch x86_64 uses a pacman package. Linux users need an unlocked Secret Service keyring for stored credentials and a file chooser portal. Make the AppImage executable before launching it.

Windows installers and AppImage support signed in-app updates. Pause or finish active transfers before installing an update.

### If macOS cannot open the app

Move S3 Studio into Applications and verify the official release source and SHA-256. Then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 桶内对象浏览器新增可展开的树状视图。每个目录汇总子目录和对象的大小、对象数，并用进度条显示占父目录的比例。默认按大小排序，也可按名称或对象数排序。
- 树状视图扫描当前目录及其子目录，从根目录进入即可扫描整个桶。搜索会展开匹配的分支，大小与占比仍以完整扫描结果为准。扫描可以取消，也可刷新重新统计。统计覆盖当前对象数据，历史版本和未完成的分片上传不计入。
- 树状视图中的文件支持查看详情、下载、复制、分享和删除。选择目录后可在确认时递归删除。

从官方 GitHub Release 下载对应平台的安装包，并用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。NSIS 和 MSI 安装包需要 Windows 10 1809 或更高版本的 x64 系统。Ubuntu 22.04+ amd64 提供 deb 包，Linux x86_64 提供 AppImage，Omarchy / Arch x86_64 使用 pacman 包。Linux 需要已解锁的 Secret Service 密钥库来存取凭据，并需要桌面文件选择 portal。启动 AppImage 前请添加执行权限。

Windows 安装版和 AppImage 支持应用内签名更新。安装更新前请暂停或完成正在进行的传输。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
