# S3 Studio 0.4.4

## English

- Added Korean, Japanese, French, German, and Russian alongside Chinese and English, including system-language detection and saved preferences.
- Localized menus, settings, file operations, transfers, help, updates, and application errors, including messages with dynamic values.
- Added English and five matching README translations, with language links on every README.
- Language options wrap within the settings panel. Language changes preserve unsaved form values and update placeholders.
- Includes the macOS titlebar theme synchronization and unified settings-saved confirmation from 0.4.3.

Supports Windows x64, macOS Universal, Ubuntu 22.04+ amd64, Linux AppImage, and Omarchy x86_64.

### If macOS cannot open the app

Move S3 Studio into Applications, verify the official release source and SHA-256, then run:

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 在简体中文、英文之外，新增韩语、日语、法语、德语和俄语，支持系统语言识别和偏好保存。
- 翻译覆盖菜单、设置、文件操作、传输、帮助、更新和应用自身错误，包括带动态参数的提示。
- 新增英文及五种对应语言的 README，每份文档均提供语言切换链接。
- 设置面板的语言选项自动换行。切换语言保留未保存的表单内容，并刷新占位提示。
- 包含 0.4.3 的 macOS 标题栏主题同步及统一设置保存提示修复。

支持 Windows x64、macOS Universal、Ubuntu 22.04+ amd64、Linux AppImage 和 Omarchy x86_64。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
