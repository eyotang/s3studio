# S3 Studio 0.4.0

- 新增主题选择：跟随系统、亮色和暗色，默认跟随系统外观，并响应系统主题变化。
- 新增统一设置面板，集中管理语言、主题及应用级共享传输并发上限（1–32 路）。
- macOS 菜单栏新增「设置…」，支持 ⌘, 快捷键；所有平台均可从侧栏打开设置。
- 语言和主题立即生效并保存到本机，重启后保留；并发设置沿用现有动态调整机制。

支持 Windows x64、macOS Universal、Ubuntu 22.04+ amd64、Linux AppImage 和 Omarchy x86_64。附件包含六个安装包、三份更新签名、更新清单和 SHA-256 校验清单。
