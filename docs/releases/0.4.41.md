# S3 Studio 0.4.41

## English

- Open **File actions** in the object toolbar to upload folders, download a selection or the current folder with its directory structure, rename files and folders, or copy and move them between buckets and workspaces. Transfers between workspaces use the credentials for each side. A move deletes a source object only after copying it and checking its revision.
- File dialogs retain the original selection, account, bucket and prefix across refreshes and retries. When filters are active, bulk actions use the matching files.
- Preview text, JSON, images, CSV, Parquet and hexadecimal data. Table and text previews are paged. Open a working copy in a local editor to upload saved changes automatically. If the remote object changes, the working copy stays on disk.
- Compare local and S3 folders, review the changed paths, and run one-way incremental sync. Save named jobs and use `s3-studio sync list`, `s3-studio sync plan <job>` or `s3-studio sync run <job>` in scripts. Sync preserves destination-only files.
- Filter recursively by path pattern, UTC dates, size and storage class. Generate expiring links for a selection or folder. Edit HTTP headers, custom metadata, tags and storage class on selected objects.
- Download specific versions directly or permanently delete selected versions after confirmation. Opening a historical download does not change the current object.

Download the package for your platform from the official GitHub Release and check it against `SHA256SUMS.txt`. The Universal DMG supports macOS 14+ on Apple Silicon and Intel. The x64 NSIS and MSI installers require Windows 10 version 1809 or later. Ubuntu 22.04+ amd64 uses the deb package. Linux x86_64 also has an AppImage, which needs execute permission. Omarchy and Arch x86_64 use the pacman package. Linux needs an unlocked Secret Service keyring and a file chooser portal. Pause or finish transfers before updating. macOS builds are Developer ID signed and await notarization.

### If macOS cannot open the app

Move S3 Studio into the Applications folder. Verify the official release source and SHA-256, then run this command in Terminal.

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```

## 中文

- 在对象工具栏打开「文件操作」，即可上传整文件夹、保留目录结构下载选中项目或当前目录、重命名文件和目录，以及跨桶和跨工作空间复制、移动。跨工作空间传输分别使用两端的凭据。移动会在复制成功并核对源对象状态后删除源对象。
- 文件操作弹窗在刷新或重试后始终沿用原先选定的对象、账户、桶和目录。使用筛选时，批量操作按匹配文件执行。
- 支持文本、JSON、图片、CSV、Parquet 和十六进制预览，表格和文本可分页查看。用本地编辑器打开工作副本后，保存修改会自动回传。远端对象发生变化时保留本地副本。
- 可先比较本地目录与 S3 目录并查看差异，再执行单向增量同步。支持保存命名任务，通过 `s3-studio sync list`、`s3-studio sync plan <任务名>` 和 `s3-studio sync run <任务名>` 调用。同步保留仅在目标端存在的文件。
- 可按路径模式、UTC 日期、大小和存储类型递归筛选，批量生成自选有效期的分享链接，并批量修改 HTTP 头、自定义元数据、对象标签和存储类型。
- 可直接下载指定历史版本，或在确认后永久删除选定版本。下载历史版本时，线上当前对象保持原样。

从官方 GitHub Release 下载对应平台的安装包，并使用 `SHA256SUMS.txt` 核对校验值。macOS Universal DMG 支持 macOS 14 及以上的 Apple Silicon 和 Intel 设备。Windows x64 的 NSIS 和 MSI 安装包需要 Windows 10 1809 或更高版本。Ubuntu 22.04+ amd64 可使用 deb，Linux x86_64 可使用 AppImage，启动前需添加执行权限。Omarchy 与 Arch x86_64 使用 pacman 包。Linux 需要已解锁的 Secret Service 密钥库及文件选择 portal。更新前请暂停或完成传输。macOS 使用 Developer ID 签名，尚未进行 Apple 公证。

### macOS 无法打开应用

将 S3 Studio 放入「应用程序」文件夹，核对官方 Release 来源及 SHA-256 后，在终端执行：

```bash
sudo xattr -d com.apple.quarantine "/Applications/S3 Studio.app"
```
