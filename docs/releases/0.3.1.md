# S3 Studio 0.3.1

- 原生应用新增简体中文和英文，默认跟随系统语言，并记住手动选择。
- macOS 通过「S3 Studio → 语言」切换，不占用侧栏空间；其他平台保留侧栏切换入口。
- 翻译覆盖菜单、账户、文件操作、传输、帮助、更新、文件选择窗口和应用自身的错误提示。
- 切换语言立即刷新界面和菜单，保留未保存的账户输入。账户名、文件名和服务端原始内容保持原文。
- macOS 应用菜单提供「关于 S3 Studio」和「检查更新…」，沿用现有版本检查与安装流程。

支持 Windows x64、macOS Universal、Ubuntu 22.04+ amd64、Linux AppImage 和 Omarchy x86_64。附件包含六个安装包、三份更新签名、更新清单和 SHA-256 校验清单。
